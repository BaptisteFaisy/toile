The frozen contract

CONTRACT.md is the single frozen source of truth. The C core and the Python twin implement it independently; the public API in section 10 is protected byte-for-byte. Changing it requires a pull request that updates the contract and both implementations together.

Output formats

Three formats, produced identically by C and Python, compared octet for octet:

$ ./build/toile-run run fixtures/boot-graphique.tcl --format text
toile v1 text
0000 TOILE_OK                   info cmd=0x0101 resource=1
# state resources=1 scanouts=1 hash=94b99b612398f675 applied=5 ...

Plus --format json (one line, frozen key order) and --format md (audit table). The state hash is FNV-1a 64 over a canonical serialization — the same sequence always yields the same hash, byte for byte (determinism).

Fixtures

Sequences of reference commands, in a small text DSL (.tcl): a boot-to-desktop sequence, resize, multi-resource, multi-scanout, cursor, and the fault cases that must be rejected with a precise verdict. Wire-level fixtures (fixtures/wire/*.hex) exercise the real little-endian encoding.

Protected API

The public API (CONTRACT.md §10) is asserted by the CI guard .github/checks/api-frozen.py: every function signature must be present in the C headers and have a Python twin — a missing symbol fails the build. Remove a symbol, and the contract complains.
